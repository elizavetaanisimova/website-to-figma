# Сервер как приложение macOS

Сервер рендеринга запускается сам при входе в систему и работает всё время,
пока компьютер включён — терминал держать открытым не нужно.

## Установка

Двойной клик по **`install.command`**.

Скрипт проверит Node.js и браузер, поставит зависимости (только в первый раз),
создаст LaunchAgent `~/Library/LaunchAgents/com.sitetofigma.server.plist`,
соберёт иконку для строки меню и сразу запустит сервер на `http://127.0.0.1:4511`.

> Если macOS скажет «неизвестный разработчик» — правый клик по файлу → **Открыть** → **Открыть**.

Дальше в Figma (desktop): **Plugins → Development → Site → Figma (Local)**.
Плагин уже ходит на `http://127.0.0.1:4511`, менять ничего не нужно.

## Иконка в строке меню

Наверху появляется значок слоёв — по нему видно состояние сервера:

| Значок | Что значит |
| --- | --- |
| Слои закрашены | Сервер работает |
| Слои контуром | Сервер запускается |
| Слои перечёркнуты | Сервер выключен вручную |

В меню: **Перезапустить сервер**, **Выключить / Включить сервер**,
**Скопировать адрес сервера**, **Открыть логи**, **Открыть лог ошибок**,
**Скрыть иконку до перезагрузки**.

Иконка — отдельное мини-приложение `Site to Figma.app` (собирается из
[menubar/main.swift](menubar/main.swift) скриптом [build-menubar.sh](build-menubar.sh),
нужны Xcode Command Line Tools). Своим агентом `com.sitetofigma.menubar` она
стартует при входе в систему. Если Command Line Tools не установлены,
install.command просто пропустит иконку — на работу сервера это не влияет.

> Иконка только показывает и переключает сервер. Закрыть иконку ≠ выключить сервер:
> «Скрыть иконку до перезагрузки» оставляет сервер работать.

## Удаление

Двойной клик по **`uninstall.command`** — автозапуск снимается, сервер останавливается.

## Полезное

| Что | Команда |
| --- | --- |
| Проверить, жив ли сервер | `curl -s http://127.0.0.1:4511/health` |
| Логи | `tail -f ~/Library/Logs/site-to-figma.log` |
| Ошибки | `tail -f ~/Library/Logs/site-to-figma.error.log` |
| Перезапустить | `launchctl kickstart -k gui/$UID/com.sitetofigma.server` |
| Остановить до перезагрузки | `launchctl bootout gui/$UID/com.sitetofigma.server` |
| Запустить снова | `launchctl bootstrap gui/$UID ~/Library/LaunchAgents/com.sitetofigma.server.plist` |
| Пересобрать иконку | `mac/build-menubar.sh` |

## Особенности

- `KeepAlive` — если сервер упадёт, launchd поднимет его снова (не чаще раза в 10 секунд).
- Сервер слушает только `127.0.0.1` — снаружи он недоступен, из сети к нему не подключиться.
- Пока никто не импортирует, Chrome не запущен: браузер поднимается на время импорта.
- После переноса папки проекта в другое место запустите `install.command` заново —
  в LaunchAgent прописан абсолютный путь.
- Порт занят? Запустите с другим: `PORT=4512 ./install.command`, затем в плагине
  измените адрес сервера в «Дополнительно».
